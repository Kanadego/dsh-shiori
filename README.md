# Shiori (栞)

为 DSH Agent 打造的四层认知记忆管理插件：常驻人设与全局记忆、图谱式自动召回的原子化记忆、自主检索的长记忆，以及自我记忆整理与记忆遗忘。支持人设卡、动态系统提示词更新，对 KV Cache 友好。

## 状态

开发中。当前仓库只放了许可协议，源码会在插件成型后再提交。
