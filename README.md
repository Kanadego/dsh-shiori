# dsh-shiori

DeepSeek Harness（DSH）的分层记忆插件。给 agent 一套有结构、能生长、也会遗忘的长期记忆。

## 它做什么

四层记忆，一层比一层长：

| 层 | 内容 | 说明 |
| --- | --- | --- |
| **L0** | 人设卡 | 常驻对话开头的身份与性格设定 |
| **L1** | core + 派生索引 | 每轮都注入的正文，加一份按需展开的 topic 索引 |
| **L2** | Spark 图谱 | 原子记忆卡，命中触发词才投递，带生命期衰减 |
| **L3** | topics | 长文档式的专题沉淀，模型主动查才展开 |

配套两个后台机制：**organize**（把散落在对话里的东西整理成结构化记忆）和 **forgetting**（双轨衰减，久不用的条目会自然淡出）。

默认 **shadow 模式**：只读、只探活，不写盘、不注入、不发请求。要真正启用得显式开 active，并给出两个绝对路径的数据根目录。卸载后记忆数据原样保留。

附带一个原生 web 面板：状态、记忆预览、预算配置、Spark 图谱的交互编辑、候选条目的审阅与确认执行。

## 状态：早期测试版，不建议安装使用

版本 `0.1.0-alpha.1`，还在被开发它的那双手反复改。

- **接口随时会变**，配置字段、工具签名、数据格式都不保证兼容。
- **可能丢数据**。alpha 阶段没有迁移路径，升级前请自行备份。
- **只在 DSH `0.2.1-rc.2` + Node 24 上跑过**，其他版本没有验证。
- 未发布到 npm。仓库里是源码，不是可安装的成品。

想看看它的设计思路可以读文档；要用在正经环境里，再等等。

## 环境

- DeepSeek Harness `>=0.2.1-rc.2 <0.3.0`
- Node.js `>=24`
