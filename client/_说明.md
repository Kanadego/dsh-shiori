# client/ 说明

- `index.js`：手写 ModuleLoader client bundle（`window.__ModuleLoader__.load`，id `dsh-shiori`）。随包可执行、无安装后构建；require 依赖仅 `react`、`zod`——二者是 Web shell 的 ModuleLoader **seeds**（预载模块），不是 npm 依赖，也不进 `dsh.client.inject`（那是客户端插件图依赖语义）。
- `shiori.css`：面板样式的评审/维护副本；运行时使用 `index.js` 内嵌的同款 CSS（`test/plugin/client.test.mjs` 断言两者规则一致，修改须同步两处）。
- 服务端 wire 冻结于 CONTRACTS §6 与 P 的 `src/plugin/protocol.mjs`；本目录不复制业务校验，输出按服务端 DTO 原样渲染。
