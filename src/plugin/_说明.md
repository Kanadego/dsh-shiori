# src/plugin — P5 可信宿主与业务 controller（slot P）

本目录是 P5-HOST-CONTROLLER 的生产层。模块职责：

- `scope.mjs` — settings 完整校验（P 侧再核验）、可信会话选卡（session → workspace
  最长边界匹配 → defaultPersona，null=global）、`pinScope` 身份固定、payload 危险
  身份字段拒绝。
- `persona.mjs` — L0 persona 独立持久 adapter：文件锁 + 内容 SHA256 CAS + 原子写 +
  持久 operationId 重放（先于 live CAS；prepared 账记 newHash，写卡后崩溃按磁盘
  hash 幂等补收尾，generation 由 revision 派生）+ lastvalid 投影（坏外改保留并
  诊断，无快照阻止 scope 启用）。
- `state.mjs` — stateRoot 持久账本：工具 operationId 重放账、L2 投递账
  （scanned/pending/accepted/committed/hit/seen/sessionEpochs）、plan 账
  （不可变 planId → plan/diff/summary；a4 起 open 计划可被更新计划作废，
  list 摘要带 superseded）、analyze operationId 重放账（a4：重放返回首次
  派生结果）、候选队列快照、L1 lastvalid 投影。
- `tool-schemas.mjs` — 16 工具输出 schema 唯一权威（真实 dsh-tools value schema
  DSL 形状：属性级 required、oneOf 联合、显式 additionalProperties）+ render。
- `protocol.mjs` — 纯 JSON 冻结 wire 契约：MANAGEMENT_METHODS（9 方法
  input/output schema）+ validateManagementPayload（闭包校验，thin-core
  UNSUPPORTED）。Q 只使用本文件；无 controller/宿主依赖。
- `typert-descriptors.mjs` — P-C：9 方法严格 typert invocation 描述符与注册
  门面（typert 服务经 readOptionalCordisService 可选读取——Cordis fiber 对未
  inject 服务的属性访问会直接抛，a5/B-P2；session lookup wire symbol 注册前
  核验；payload parse 恒等——校验独家在 service 层；失败/漂移一律回退 SRC
  不抛出；上一代未 withdraw 且逐字一致则 adopt）。
- `management.mjs` — 管理 API 生产实现（getStatus/getMemoryView/getGraph/
  executeTool/listCandidates/analyze/reviewCandidate/previewPlan/executePlan）；
  shadow（含 inert）仅纯内存 getStatus（不触盘、不建锁），其余 UNSUPPORTED /
  NOT_CONFIGURED；executePlan 仅本次调用授权（stop/断连撤销、重试与 merge 退休前
  重验；已 abort 的 signal 在 grant 注册入口即撤销，executor 前与 markExecuted 前
  各有一次显式取消核验，plan 保持未执行）且 plan 一次性（已执行拒绝重跑）。
- `bindings.mjs` — 真实 ctx 生产接线（systemPrompt.section、
  system-prompt/assemble waterfall、agent/pre-step、session/event、真实
  defineTool output:{schema,render}、dsh-llm createUserMessage）；DSH 包经
  import.meta.resolve 解析并验证导出形状；`detectCompletePromptSections` 只读
  layers.global 做三态探测（{state:"ok"|"none"|"unavailable"}，别的 scope 的
  complete section 不参与全局判定）；`detectCompleteSectionsForScope` 用宿主
  同一份 layers.merge(scope) 判定本次装配是否被 complete 快照遮蔽；不可判定时
  controller 不得据此报 l0l1Effective:true；缺能力 UNSUPPORTED。
- `controller.mjs` — `createShioriPluginController(ctx, settings, dependencies)`：
  构造不自动 start；start/stop 互锁（stop 等在途 start 收场；management 数据方法
  全部纳入在途排空，带上限、未收场项进 stop().errors）且幂等、失败逆序清理；
  inert / shadow（纯内存）/ active 三形态；workspace 经宿主 workingDirectory.get
  （只读，压缩事件归属同源，header.cwd 不参与）接入选卡；同 scope 资源复用；
  L0/L1 真实 async waterfall 刷新（逐段错误隔离；complete 遮蔽只按本次装配的
  scope 判定（宿主会剥掉入口 section 的 complete 标记），命中即记账
  assemblyCompleteShadowed 并原样返回、不刷新不计数）；L2 pre-step 投递（真实 surface append 才
  accepted；崩溃恢复按 Message.id 回查会话日志）；写工具按 (scope,tool) 串行化；
  压缩探针 + 每 session epoch；16 工具注册。

不 import Q 的 config.mjs / client-rpc.mjs；settings 由 Q 归一化后传入并在
scope.mjs 完整再校验。
