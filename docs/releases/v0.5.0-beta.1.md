# v0.5.0-beta.1

这一版把「记忆会自己变冷」补上了：专题有了温度、可以自动归档与恢复，面板也按「读」和「写」重新分家。这是测试版，自动冷却建议先只观察。

### 新增功能

- 专题生命周期：每条专题可选「长期保留」或「有来有去」，归档时记录是手动还是自动，L1 索引改为「活跃专题 + 分组摘要行 + 组内置顶专题 + 冷专题钩子」的布局
- 温度引擎：按稳定性与热度两个值给每条专题算 active / cool / cold / frozen 四档，纯函数、可按时间回放，面板能预览「如果开自动，哪些会变冷」
- 自动冷却与恢复：只做可逆的归档与还原，每轮最多 20 条，带审计记录与一键撤销，拆篇、合并、改写正文这类动作永远不会自动执行
- 参数面板：温度相关的 12 项参数集中在一处，改完即刻生效，支持回放模拟
- 面板重排为八个页签：概览只读、专题整理承接全部写操作、闪回图谱带分页与命中列表、人设与核心独立成页、最近变更合并成一条流
- 设置页拆成四个子页：预算、温度、闪回卡片、向量召回
- 专题可挂多个分组，删组时可把成员一并迁移，遗留的悬空引用能一次清掉

### 改进

- 专题页只读，编辑人设卡与核心正文回到「人设与核心」页，不再和专题混在一起
- 专题整理的「记忆整理」与「候选审阅与执行」拆成二级分页，来回切换不会丢掉已勾选的候选
- 闪回命中与最近命中的每页条数统一，翻页不再跳来跳去
- 人设切换收进编辑卡内，顶部不再有重复的选卡条；切换失败会明确报错
- 设置页「预算」子页去掉重复的闪回卡片段落，只在「闪回卡片」子页配置
- 温度档位切换不需要重启 DSH，改完即生效
- 归档条目在搜索结果里排在活跃条目之后，冷卡不带分数

### 修复

- 面板切换温度档位时被宿主拒绝、提示配置项不是 volatile，已整段改为可热改
- 启动时的差集门控改用实际收场信号，不再靠固定等待
- 读分组越界或父分组悬空时降级为提示，不再整页失败
- 分组相关错误码统一，删组并发时不会留下半迁移状态
- 突发中断后状态恢复不再依赖机器速度

### 注意

- 这是测试版：温度与自动冷却涉及「记忆会自己变冷」，建议先把自动模式设为只提示，观察一段时间再放开
- 面板信息架构有较大调整，旧的页签入口已做别名跳转，但收藏的深链可能需要重新点一次
- 默认安装仍指向 0.4.0；想试这一版请安装 `dsh-shiori@next`
