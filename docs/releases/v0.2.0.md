# v0.2.0

本版本把记忆从「能记住」推到「能想起来」：新增本地语义召回、闪回命中可见性、最近变更页与只读降级，并修复两个会导致插件无法启动的问题。

### 新增功能

- 本地语义召回（默认关闭）：在本地计算 embedding 向量并做余弦近邻，结果合并进闪回投递
- 使用 `Xenova/bge-small-zh-v1.5`（512 维），默认 fp32，可选 q8 / fp16
- 包内不附带模型，首次使用时下载（fp32 约 91MB），支持配置镜像源，国内可用 `hf-mirror.com`
- 语义召回按需加载，未启用时不会 import 相关模块
- 召回失败时静默回退为纯字面匹配，诊断信息写入状态页，可在面板手动重建
- 相似度下限 `semantic.minSimilarity` 可配置，默认 0.55
- 新增「闪回命中」tab：从未被命中的卡片（含存续天数）、命中 top10、投递吞吐
- 消息底部新增入口按钮，可查看本次投递命中的卡片
- 新增「最近变更」tab：core / 主题 / Spark 的操作时间线，支持分页、去重标注与跳转定位
- 同一数据目录被多个端打开时按座位判定：先启动者可写，后启动者只读且不阻塞启动
- 只读状态下面板顶部显示占用者 PID，写按钮置灰

### 改进

- 面板统一为红→金主题，字段行改为「标题 / 控件与恢复默认 / 后果说明」三段式
- 保存结果改为右下角 toast 加页内横幅，8 秒自动收起
- 宿主 bridge 路径在每次写入前复核，拒写时返回 `HOST_LOCKED`

### 修复

- 修改 `hardCapChars` 后插件无法启动：schema 注入的静态默认值覆盖了派生水位
- 宿主 ctx 冻结时客户端入口一直 loading
- 时间线去重发生在截断之后，导致去重后整页缩水、`hasMore` 提前为 false
- L1 投影每轮重写，导致签名判等永远不成立
- 陈旧锁导致永久只读：判定外部持有者时未检查 pid 存活
- 只读探针把自身 pid 当作外部持有者，长写被自我拒绝
- 保存成功但需要重启的提示不再无限停留

### 注意

- 语义召回依赖 `@huggingface/transformers`，安装时需允许运行安装脚本（`onnxruntime-node` / `protobufjs` / `sharp`）
- 与 `dsh-soul-md` 提供同名工具，两者需二选一
- 桌面版由 Electron 独占 profile，同一份 profile 不能同时给 web 与 desktop 使用
