# dsh-shiori v0.2.0

这一版把记忆从「能记住」推到「能想起来」。四个新能力：本地语义召回、闪回命中可见性、最近变更页、只读降级；顺手补掉两个会让插件起不来的 P0。

## 新增

### 本地语义召回（默认关闭）

以往 Spark 只能靠触发词字面命中。这一版加了本地 embedding：句子进来先在本地算向量，跟卡片做余弦近邻，再合并进投递结果。

- 模型 `Xenova/bge-small-zh-v1.5`（512 维），**fp32 默认**，`q8` / `fp16` 可选
- 包内**不带模型**：首次使用才下载（fp32 约 91MB），镜像可配，国内可用 `hf-mirror.com`
- 懒加载：不开这个功能就一行代码都不会 import
- 失败静默回退纯字面召回，错误写进状态页诊断，可在面板手动重建
- 置信度下限 `semantic.minSimilarity` 可配（默认 0.55）。实测 24 条夹具：0.45 命中 21/24 但多捞 17 张；0.60 命中 16/24 多 4 张；**0.70 起等价于纯字面**

### 闪回命中可见性

新增「闪回命中」tab：哪些卡片从未被命中（含存续天数）、命中 top10、以及投递吞吐（重复投递率 = 1 − 去重卡片数 ÷ 总投递张数）。消息底部也加了入口按钮，点开就是这次投递命中了什么。

口径写在页面上：只覆盖 L2 开启期间的投递，命中也**不代表被采用**。

### 最近变更页

core / 主题 / Spark 的操作时间线，按时间去重合并，支持分页、去重标注、扫描截断提示，以及对已存在的条目一键跳转到对应 tab 定位。

### 只读降级（多端）

同一个数据目录被两个 DSH 端打开时，按**座位心跳**判定：先启动者持座可写，后启动者只读，且不阻塞启动。

- 只读时面板顶部出黄条（写明被哪个 PID 占用），所有写按钮置灰
- 宿主 bridge 路径每次写前复核，拒写时返回 `HOST_LOCKED`
- 座位只按 pid 存活回收，先来者卡住时后来者保持只读，不会双写

## 面板

八个 tab：状态 / 最近变更 / 记忆 L0·L1 / 图谱 / 候选·计划 / L3·主题 / 闪回命中 / 预算配置。这一版统一了红→金主题，字段行改成「标题 / 控件+恢复默认 / 后果说明」三段式，保存后的提示改成右下角 toast + 页内横幅（8 秒自动收起）。

## 修复

- **改 `hardCapChars` 后插件起不来**：schema 给 `softChars`/`hardChars` 注入了按默认硬顶算的静态默认值，把派生水位顶掉了，启动即报 `core.targetChars must be < derived hardAt`
- **宿主 ctx 冻结时客户端入口永远 loading**：可选便利入口的赋值在严格模式下抛错，整个 apply 变红
- 时间线去重放在截断之后，导致去重后整页缩水、`hasMore` 提前为 false
- L1 投影每轮都重写（`savedAt` 恒变，签名判等永远不等）
- 陈旧锁导致永久只读：判定外部持有者时不查 pid 存活，死主锁会把自己锁死在只读
- 只读探针把自身 pid 当成外部持有者，长写会自我拒绝
- 保存成功但需重启的提示不再无限挂屏

## 兼容与限制

- 需要 DSH `>=0.2.1-rc.2 <0.3.0`、Node `>=24`
- 语义召回依赖 `@huggingface/transformers`，安装时需要**允许运行安装脚本**（`onnxruntime-node` / `protobufjs` / `sharp`），DSH 插件管理器会提示
- 和 `dsh-soul-md` 提供同名工具，二选一
- 桌面版由 Electron 独占 profile，同一份 profile 不能同时给 web 和 desktop
