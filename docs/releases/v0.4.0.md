# v0.4.0

本版本把「装完就能用」这条线打通，并补上分组、分页、模型下载、卸载焚毁与图谱两级视图。

### 新增功能

- 数据根与状态根默认落到 `<DSH_HOME>/shiori-data`、`<DSH_HOME>/shiori-state`，挂载时自动创建；缺配置时面板给「启用记忆」按钮与初始化卡片
- 侧边栏新增「记忆」入口，点开直达全屏面板
- 专题支持多分组归属（首个为主组）与置顶，新增 `group_manage` 工具与分组管理界面
- 最近变更、专题导航、专题列表、闪回命中统一每页 10 条
- 设置页可设工作区默认人设卡，会话顶部可切换，切卡即换整套记忆
- 状态页可一键下载语义模型到数据目录，带进度，失败时可手动指定目录
- 新增 `dsh-shiori-admin` 命令（`destroy` / `status`）与面板危险按钮，二次确认后删除整个数据目录
- 图谱首屏只画簇圆，点开进簇内再画连线，带面包屑

### 改进

- 包内携带 `scripts/` 与 `test/`，装包后可原地运行 `npm test`
- `group_manage` 新增 `repair` 动作，`list` 同时返回 `dangling`
- 图谱节点带实体标签，图例「填充=实体聚类，描边=存续类型」名副其实

### 修复

- 进簇过渡期不再闪「当前 scope 无 active 卡」的假空态
- 时间线回退时偏移量不再可能为负
- 清簇时地图不再被清空
- 迁移目标的断言不再写死具体组名
- 换模型后自动重建改为强制全量，旧维度向量不再残留
- 数据根或状态根落在 junction / symlink 上不再启动即失败

### 注意

- L1 索引仍平铺，分组只影响专题页的归类与展示
