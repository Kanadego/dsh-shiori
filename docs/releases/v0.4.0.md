# v0.4.0

本版本把「装完就能用」这条线打通，并补上分组、分页、模型下载、卸载焚毁与图谱两级视图。

### 新增

- **首次安装可用性**：数据根与状态根默认落到 `<DSH_HOME>/shiori-data`、`<DSH_HOME>/shiori-state`，挂载时自动创建；shadow 态面板顶部给「启用记忆」按钮，缺配置不再只有一行黄字，改为一张说明缺什么、可一键初始化的卡片。
- **侧边栏独立入口**：侧边栏出现「记忆」图标，点开直达全屏面板；插件详情页入口保留。
- **专题分组**：专题 front-matter 支持 `group` 多组归属（首个为主组）与 `pinned` 字段，新增 `group_manage` 工具与分组管理 UI；L1 索引仍平铺，折叠读法留待后续版本。
- **面板分页**：最近变更、专题导航、专题列表、闪回命中统一每页 10 条，机器串隐去只留友好日期。
- **人设卡切换**：插件设置页可设工作区默认卡，会话顶部加选卡按钮；切卡即换整套记忆，切换后有一行提示。
- **模型下载**：状态页可一键下载语义模型到数据目录下的 `models/`，进度按字节加权聚合；优先镜像源，全失败时给手动指定目录与可复制的安装提示词。
- **卸载与焚毁**：新增 `dsh-shiori-admin` 命令（`destroy` / `status`）与面板危险按钮，二次确认后删除整个数据目录；状态目录与 DSH 配置不动。
- **图谱两级视图**：首屏只画簇圆（簇 = 组或按向量聚的类），点开进簇内再画连线，带面包屑；新增 `level` / `cluster` 参数，全量返回保留兼容。

### 修复

- 进簇过渡期不再闪「当前 scope 无 active 卡」的假空态，焦点卡不再误报「可能已删除或已归档」。
- 时间线回退时偏移量不再可能为负，下界钳到 0。
- 清簇时地图不再被清空。
- 迁移目标的断言不再写死具体组名。

### 变更

- 数据根与状态根独立解析、独立校验，缺省回落到 `<DSH_HOME>` 下；只读挂载不再由缺根触发。
- 面板在侧边栏与详情页各注册一个槽位，详情页卡片改为全屏容器。
- 测试按开发层与发版层分两条线跑。
