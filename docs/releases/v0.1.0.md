# dsh-shiori v0.1.0

首个正式版本。dsh-shiori 是给 DSH 用的长期记忆插件：把「人设、记忆、闪回、专题」分成四层管起来，在有限的上下文预算里决定每一轮该想起什么、该忘掉什么。

## 四层记忆

- **L0 人设卡**：整张常驻，占用多少算多少
- **L1 记忆核心**：常驻正文 + 一条派生索引（索引按预算自动压缩，正文永不截断）
- **L2 Spark 图谱**：原子卡片，只有触发词命中才投递
- **L3 主题记忆**：整篇按关键词单独调阅

## 这一版能做什么

| 能力 | 说明 |
| --- | --- |
| 预算自治 | 软/硬两档水位，超软水位自动把实操记录下沉到专题，超硬水位必须清理；人设卡与索引共享预算、索引优先 |
| 许愿瓶 | 多轮写入走 epoch 与 CAS，版本冲突拒绝覆盖，重试幂等（operationId） |
| 整理与遗忘 | 后台把散落的记录归并进专题、给长期不用的卡片降权，归档不删除 |
| 原生面板 | 状态 / 记忆 L0-L1 / 图谱 / 候选计划 / L3 专题 / 预算配置 六个 tab，全部中文化，人设卡与记忆核心可直接就地编辑 |
| 图像化回忆 | Spark 图谱可缩放、可连线、可撤销未保存的改动 |
| 影子模式 | 默认 shadow：只读不写，配置齐全后手动切 active |

## 安装

```powershell
dsh plugin --profile web add dsh-shiori
```

装上后是 inert shadow，需要在预算配置或 `cordis.patch.yml` 里补 `mode: active` / `allowActive: true` / 两个绝对路径目录才会开始读写。

## 兼容与限制

- 需要 DSH `>=0.2.1-rc.2 <0.3.0`、Node `>=24`
- 和 `dsh-soul-md` 提供同名工具，同时启用会被宿主的工具唯一性校验拒绝，二选一
- 桌面版（desktop profile）由 Electron 独占，同一份 profile 不能同时给 web 和 desktop
- 面板的会话列表依赖宿主 `workspaces` 服务；宿主不提供时退化为平铺的会话列表
