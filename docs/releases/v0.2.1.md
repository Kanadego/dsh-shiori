# v0.2.1

本版本重做了「整理与遗忘」页面，并修复三处会导致操作中断的问题。

### 新增功能

- 待处理候选按集群 / 可建链接 / 孤立卡分组，组头显示数量，孤立卡默认折叠
- 候选列表支持按状态筛选（全部 / 待处理 / 已阅 / 已忽略）与关键词搜索
- 候选行下方显示建议理由，说明两张卡共享的实体或触发词
- 「预览整理计划」的预览卡渲染在对应候选行正下方，不再跳到页面底部
- 预览卡按计划类型区分正文与确认按钮文案
- 存在过期候选时，面板顶部显示提示条与「重新分析」按钮

### 改进

- 「标记已阅」更名为「稍后再说」，明确它只收起候选、不删除记忆
- 错误提示改为中文场景描述与下一步动作，原始错误码收进「技术细节」折叠区
- 过期候选行显示「卡片已改」徽章，预览与合并按钮置灰，「稍后再说」「忽略」仍可用
- 孤立卡不再提供预览入口——它没有第二张卡可连
- 手写 proposal 的入口收进默认折叠的高级区
- 计划执行成功后，对应候选从队列中移除；需要重新分析才能再次预览同一对卡
- 页面底部原有的全局 proposal 文本框已移除

### 修复

- 点击第二条候选必然返回 INVALID_INPUT：全局单一文本框把候选串了
- 孤立卡的「预览整理计划」必然返回 INVALID_INPUT：骨架取不到第二张源卡
- 连线执行后队列未收敛，同一对卡二次连线返回 REVISION_CONFLICT
- 服务端新增的未知候选类型被静默丢弃，不进任何分组
- REVISION_CONFLICT 提示指向「刷新」，但刷新只重读队列快照、不会重新分析

### 注意

- 「已阅」「已忽略」暂无撤销入口
- 整理与结网会写入 `sparks.json`，首次使用前建议备份一次 `dataRoot`
- 面板上的「刷新」只重新读取队列快照，重新分析请点「分析整理候选」
