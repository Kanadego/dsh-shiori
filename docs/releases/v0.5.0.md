# v0.5.0

0.5 正式版。相对 0.5.0-beta.1，功能面没有新增，改的都是试用时记下的小毛刺与观感问题：遗忘归档关闭时整理页不再一片空白，闪回卡片设置里跑错页的 L0 参数归位，概览的冷热分布改成一排彩块，技术细节/完整 DTO 这类给人看也没用的原始字段整体下线，数据删除搬到设置页单独一页，整理页四块改成互斥手风琴并删掉早已停用的候选与计划，刷新按钮每页只留一个，hero 渐变重做，设置页统一成一套分页样式。

### 新增功能（同 0.5.0-beta.1）

- 专题生命周期：每条专题可选「长期保留」或「有来有去」，归档时记录是手动还是自动，L1 索引改为「活跃专题 + 分组摘要行 + 组内置顶专题 + 冷专题钩子」的布局
- 温度引擎：按稳定性与热度两个值给每条专题算 active / cool / cold / frozen 四档，纯函数、可按时间回放，面板能预览「如果开自动，哪些会变冷」
- 自动冷却与恢复：只做可逆的归档与还原，每轮最多 20 条，带审计记录与一键撤销，拆篇、合并、改写正文这类动作永远不会自动执行
- 参数面板：温度相关的 12 项参数集中在一处，改完即刻生效，支持回放模拟
- 面板重排为八个页签：概览只读、专题整理承接全部写操作、闪回图谱带分页与命中列表、人设与核心独立成页、最近变更合并成一条流
- 设置页拆成五个子页：预算、温度、闪回卡片、向量召回、数据与卸载
- 专题可挂多个分组，删组时可把成员一并迁移，遗留的悬空引用能一次清掉

### 转正修复

- 遗忘归档关闭时，「专题整理 → 记忆整理」不再只剩运行状态：补一张「遗忘归档 · 未开启」卡，一键写入 `forgetting.enabled=true`，写回后回读确认，自动整理热生效时提示「已开启」，未热生效则如实提示重启后可用
- 「设置 → 闪回卡片」子页不再混入 L0 的「人设卡最大字符数」；该项只出现在「预算」子页（L0 只出现一次）
- 「最近变更」页给主列表加了「记忆改动（N 条）」分隔标题，审计流卡片与主列表不再看起来连成一片
- main 槽位顶部留白改为 `max(64px, 24px + clearance)`：宿主没提供顶部 clearance 时，hero 标题块不再被顶栏压掉一截
- 概览「冷热分布」从一行小字改四块彩块：中文分级名 + 大数字 + 一句解释，四档各用自己的色，扫一眼就有数
- 概览与各页的「技术细节（原始字段）」「完整 DTO」「原始节点数据」等折叠区整体裁撤——这些原始字段对人没有信息量；保留的是可读的状态文案与错误码
- 「已启用的能力」补上「语义召回」标签，标签样式由实心填充改为描边高亮
- 「卸载并清除数据」从「专题整理」页底折叠里搬出来，在「设置 → 数据与卸载」单独一页（危险操作端到端逻辑不变，二次确认仍要照抄 dataRoot 原文）
- 专题整理「索引与分组」窗格只留「专题索引归档」与「分组管理」两块，改成互斥手风琴：点开一块自动收起另一块；早已停用的「候选审阅」与「计划」整块下线
- 刷新按钮收敛：每页最多一个（运行状态一枚同时刷新状态与整理状态，最近变更一枚同时刷新主列表与审计流）
- hero 渐变重做：石榴红 → 紫 → 金黄三段柔化过渡，去掉中间发黑的一段；壳条与 hero 均标记 `flex:none`，长列表不再把它们压扁
- 设置页统一样式：分页胶囊条 + 每页一条标题带（标题 + 一句副标），子页内容共用同一套卡距与描边

### 兼容与升级

- 从 0.4.x 升级：按 `docs/plugin/INSTALL.md` 正常升级即可，数据结构沿用 0.5.0-beta.1
- 从 0.5.0-beta.1 升级：直接覆盖安装，无需迁移
- 自动冷却默认仍是「建议（不自动执行）」；想让它自己动，需要先开启遗忘归档、再把模式切到「自动」
